---
title: onBeforeToolCall
---

The `onBeforeToolCall` event fires when the LLM requests a tool, but *before* Fragola actually executes the tool's handler function.

## Usage
This event allows you to intercept the tool execution. It is heavily used in advanced patterns to:
- Override or rewrite the arguments (`params`) provided by the LLM before they reach your handler.
- Bypass the handler entirely by providing an `injectConfig` (useful for caching or remote tools).

### Payload Details
```typescript
agent.onBeforeToolCall(({ config, toolCall }) => {
    // Check which tool is being called
    if (toolCall.name === "getWeather") {
        // You can rewrite the parameters the LLM provided
        if ("params" in config && config.params.city === "NYC") {
            return {
                params: {
                    ...config.params,
                    city: "New York City"
                }
            };
        }
    }
    
    // Or completely bypass execution by providing a raw payload response
    if (toolCall.name === "expensiveTool") {
        return {
            injectConfig: { success: true, data: { status: "cached result" } }
        };
    }
});
```
